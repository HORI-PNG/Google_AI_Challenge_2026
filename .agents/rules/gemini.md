# Gemini API の使い方

- アプリの中の AI 機能は、すべて Gemini API で実装する（応募条件：Google AI を主要な制作手段にする）
- Gemini API はサーバー側からだけ呼び出す。API キーをブラウザに出さない
- モデル名はコードに直接書かず、環境変数 `GEMINI_MODEL` で切り替えられるようにする
- 日記の整理は構造化出力（JSON スキーマ指定）を使い、PLAN.md の出力形式に合わせる
- 音声日記は、音声データをそのまま Gemini に渡して文章にする
- プロンプトは `src/prompts/` にまとめ、Google AI Studio で試したものと同じ内容にする
- Gemini の応答が失敗したり形式が崩れたりしても、日記の本文は必ず保存する
