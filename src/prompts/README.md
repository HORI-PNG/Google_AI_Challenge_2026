# プロンプトの試作（Google AI Studio）

Re:Note で Gemini に渡すプロンプトの置き場所。
ここで Google AI Studio で試したものを、そのままアプリでも使う（`.agents/rules/gemini.md` のルール）。

| ファイル | 中身 | 出力 | Temperature |
|---|---|---|---|
| `01_diary_analysis.md` | 日記の分析（感情の点数化、学んだこと、キャラのひとこと） | JSON | 0.3 |
| `02_forecast.md` | 今日のはかどり予報と過ごし方の提案 | JSON | 0.6 |
| `03_character_chat.md` | キャラクター「ハカドリ」との会話 | 文章 | 0.9 |
| `04_voice_transcription.md` | 声の日記の書き起こし（音声をそのまま渡す） | JSON | 0.1 |
| `test_data.md` | テスト用の日記 8 件、14 日分の記録 | — | — |

---

## Google AI Studio での試し方

1. https://aistudio.google.com を開き、Google アカウントでログインする
2. 新しいプロンプト（チャット）を作る
3. 右側の設定で
   - モデル：Gemini の Flash 系（速くて安いので、アプリでもこれを使う想定）
   - Temperature：上の表の値
   - ①②④：**Structured output（構造化出力）をオンにし、スキーマの編集画面に各ファイルの「出力スキーマ」を貼る**
   - ④だけ：メッセージ欄に、自分で録音した音声ファイルを添付する
4. **System instructions** に、各ファイルの「システム指示」を貼る
5. メッセージ欄に `test_data.md` の入力を貼って実行する
6. 結果を下のチェックリストで確認し、気になる所があればシステム指示を直して、もう一度実行する
7. うまくいったら、直したシステム指示をこのフォルダのファイルにも反映する

> **動画用に**：AI Studio で日記を貼って点数が返ってくる画面を、画面録画しておく。
> デモ動画の「Google AI の使用場面」にそのまま使える。

## よくある直し方

| 起きたこと | 直し方 |
|---|---|
| 点数が毎回大きくぶれる | Temperature を下げる。システム指示に点数の目安（例：「へとへと」は energy 20 前後）を足す |
| 全部の点数が 50〜70 に寄る | 「迷ったら 50」の指示が効きすぎている。「はっきり書かれている気持ちは、0〜30 や 70〜100 も使う」と足す |
| evidence の数字が間違う | アプリ側で集計した数字（例：focus 70 以上の日のはかどり率）を入力に入れ、Gemini には文章にするだけを任せる |
| キャラの返事が長い | 字数の指示を文頭に移す。例として良い返事を 2〜3 個書き足す |

> evidence の数字はモデルが数え間違えることがあるので、本番では **集計はアプリのコードで行い、結果を Gemini に渡す** 形にするのがおすすめ。
