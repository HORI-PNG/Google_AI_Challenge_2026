## 🎩 Ver.2 の進化ポイント（後ろ歩きの完全再現）

### 1. なぜ「前歩き」に見えていたのか？ → 物理の修正
- **Ver.1**: キャラが右向きで、床が「右から左」へ流れていました。これは「右に向かって前進している」のと同じ光景に見えてしまう原因でした。
- **Ver.2**: マイケルが「右（前）」を向いたまま、床と障害物が「**左から右へ**」流れます。自分が後ろ（左）へと後退しているからこそ周りの景色が右へと流れるという**正しい光学物理（Optical Flow）**を適用したことで、**誰が見ても「後ろに滑っている（ムーンウォークだ！）」**と認識できるようになりました。

### 2. Moonwalkerゲーム特有のスーパーアクション
1. **足元から吹き出すスターダスト魔法（Stardust）**  
   ムーンウォーク中、靴底からキラキラ光る星の粒子が後方へ吹き出します。
2. **25%: ハイキックまたぎ**  
   背後から迫るゴールドコインを、振り返りざまの切れ味鋭いハイキックステップで華麗にクリア！
3. **36.5%〜46%: ゼログラビティ（Smooth Criminal Lean）＆スピン**  
   体全体がピンと伸びたまま斜め45度前に倒れる奇跡の前傾姿勢！  
   「Hee-Hee!」のシャウトと共に空中360度スーパースピンでアンプを跳び越え、着地でキメます。
4. **54%: ハットトス（帽子投げ必殺技）＆「Aaow!」**  
   小石につまずいた瞬間、「Aaow!」と仰け反りながら帽子をブーメランのように前方にスロー！空中で回転して戻ってきた帽子を手元でキャッチし、華麗に体勢を立て直してムーンウォークを再開します。
