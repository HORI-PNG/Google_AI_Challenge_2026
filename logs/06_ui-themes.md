# 段階6：UI テーマと全画面の見た目（記録）

## 決めたこと（ユーザーに確認済み）
- デザインは Figma Make で作り（指示書 `design/figma-make-brief.md`）、Next.js に移植した
- テーマは **7 種類**：手帳の系統（ことり・よぞら・もりのとしょかん・ソーダ・さくらもち）、クリア、ビジネス。メタルはやめた
- テーマの選び方：自分で選ぶ ＋ 気分でおすすめ
- 学年の選択肢は今のまま（大学1〜4年）
- Figma Make のファイルはソースだけコミット（動作用のファイルとダウンロードの記録は `.gitignore`）

## 実装したこと
- `src/lib/themes.ts`：テーマの定義（系統 `notebook`／`glass`／`office`）と、気分でのおすすめ（ストレス高め → もりのとしょかん、22〜3時 → よぞら、気分が高い → ソーダ、ふつう → ことり）
- `src/app/globals.css`：Figma の各テーマの変数・背景の模様・すりガラスを移した。Tailwind のクラス（`bg-card`、`font-display` など）からも使える
- フォントは `next/font`（Zen Maru Gothic、M PLUS Rounded 1c、Klee One、Noto Sans JP、Roboto Mono）。標準テーマ以外は先読みしない
- テーマの保存：Firestore の `settings.themeId` を正とし、ブラウザにも控えを置く。`layout.tsx` の描画前のスクリプトで `data-theme` を付け、開いた瞬間のちらつきを防ぐ（`ThemeProvider`）
- 共通の部品 `src/components/ui/`（Button、Card、BackHeader、SpeechBubble、ScoreBar、Mascot）
- 画面：ログイン、はじめまして、ホーム（系統ごとに3つの構成）、日記（書く・話す・選ぶ）、分析中、結果、つらい気持ちのとき、分析失敗、気分のグラフ、**テーマ・設定（`/settings`、新規）**
- ホームの「はかどり予報」は見た目だけ置き、「日記がたまると出ます」と表示（中身は段階8・9）
- グラフの4色：Figma の色は暗いテーマで決まりの範囲を外れたため、検証済みの組み合わせに揃えた（明るいテーマ／暗いテーマで1組ずつ。7テーマとも合格）
- `design/` を TypeScript・ESLint の対象から外した
- テスト `tests/unit/themes.test.mjs`（8件）

## 変わったこと
- テーマを選ぶと、色・フォント・背景に加えて、ホームの構成も変わるようになった
- 気分と時刻から、合うテーマをすすめるようになった
- 選んだテーマはアカウントに保存され、別の端末でも同じになる

## 動作確認
- `npm test`（43件）、`npm run lint`、`npx tsc --noEmit`、`npm run build`：成功
- 架空のデータの確認用ページ（コミットしていない）で、ホーム・結果・つらい気持ちのときの画面を 7 テーマ × 375px で撮影して確認
- ログイン・項目選択・グラフ・設定の撮影は、時間を優先して省いた（ユーザーがブラウザで確認する）

## 残った課題・引き継ぎ
- 「はかどり予報」「昨日ははかどった？」は段階8・9 で中身を入れる
- ハカドリの表情を点数で切り替える仕組みは段階7
- 予報がないときの「--」は丸い字体で2本の線に見える（予報が出れば数字になる）
- 事前描画のときに「今の時刻」を読むと、Next.js 16 のビルドが止まる（設定画面は `useSyncExternalStore` で回避済み）
