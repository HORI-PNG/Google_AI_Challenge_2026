# 段階7：キャラクター（表情の切り替え、話しかけ）（記録）

## 決めたこと（ユーザーに確認済み）
- ハカドリとの会話（mode: chat）は入れない。余裕があれば段階11 以降
- 表情の切り替え ＋ 日記を書く前の話しかけ、で進める

## 実装したこと
- `src/lib/mascotMood.ts`：点数から表情を決める（つらい気持ち・ストレス70以上・気分40未満 → 心配／元気35未満 → ねむい／気分70以上 → にっこり／集中70以上 → おうえん／それ以外 → ふつう）
- 表情を使う場所：ホームの話しかけ、最新の日記のふりかえり、ビジネスのホーム、結果の画面、日記を書く画面
- `POST /api/character`：プロンプト③（`src/prompts/03_character_chat.md`）で、最近の日記 3 件（本文の先頭 60 字と点数）、日時、学年から話しかけを作る。名前とニックネームは送らない
  - 段階3 のやり直し・Gemini モデルの切り替えを使う（待たせないよう 1 モデル 2 回まで）
  - `generateText`（文章で返す呼び出し）を `src/lib/server/gemini.ts` に追加
- `src/lib/characterMessage.ts`：プロンプトへの入力の組み立て、返事の確認（空・100 字超えは使わない）、決まった話しかけ（日付ごとに 1 つ）
- `src/components/useGreeting.ts`：話しかけと表情を用意する。同じ日・同じ最新の日記なら、タブを閉じるまで使い回す（Gemini の回数の節約）。失敗したら決まった話しかけ
- 話しかけの表示：ホーム（手帳＝吹き出し、クリア＝すりガラスの帯、ビジネス＝見出しの下の一行）、日記を書く画面の上
- テスト `tests/unit/character.test.mjs`（12 件）

## 変わったこと
- ハカドリが最新の日記の点数に合わせて表情を変えるようになった
- ハカドリが最近の日記をふまえて、具体的な質問で話しかけるようになった（日記を書くきっかけ）

## 動作確認
- `npm test`（55 件）、`npm run lint`、`npm run build`、`npx tsc --noEmit`：成功
- 架空の日記で話しかけを試した：`gemini-3.5-flash-lite` で「昨日言ってた数学の平方完成、テストに向けてうまく練習できた？ピッ。」（33 字）。`gemini-3.8-flash` は 504
