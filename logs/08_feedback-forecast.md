# 段階8：「昨日ははかどった？」と今日のはかどり予報（記録）

## 決めたこと（ユーザーに確認済み）
- 「はかどった？」は 3 段階に加えて、時間帯（朝・昼・夕方・夜）と場所（家・図書館・カフェ・学校・公園）を任意・1 タップで聞く
- 予報は 1 日 1 回作って使い回し、その日に新しい日記を書いたときだけ作り直す
- **予報は、今日の気分を入力しなくても出す**（アプリの目的：「今日は、どこで・何を・いつすればいいか」を、これまでの日記から予測する）。昨日・今日の日記があれば材料に足す
- 予報には「この予報は、これまでの日記をもとに AI（Gemini）が予測したものです。ご参考までに。」と必ず添える
- 分析中のアニメーションは、ハカドリ（PR #9 の ver1）を標準にし、設定でムーンウォーク（ver2）・メガシティ・バトル（ver3）に切り替えられる

## 実装したこと
### 「昨日ははかどった？」
- `src/components/home/FeedbackCard.tsx`：昨日の日記があって未回答のときだけ、ホームに出す。3 段階は 1 タップで保存、時間帯・場所は先に選んでおけばいっしょに保存。「あとで答える」もある
- 保存先：`users/{uid}/feedback/{昨日の日付}`（`src/lib/feedback.ts`）
- 答えたらハカドリが決まった文でお礼を言い、そのあと予報を出す（答えを予報に使うため、答えるまで予報を待つ）

### 今日のはかどり予報
- `POST /api/forecast`：プロンプト②（`src/prompts/02_forecast.md`）を読み込み、構造化出力・Temperature 0.6。段階3 のやり直しと Gemini モデルの切り替えを使う
- 入力（`src/lib/forecast.ts`）：過去 30 日の日ごとの記録（平均点・曜日・気持ちのラベル・答えていれば「はかどった？」と時間帯・場所）と、昨日・今日の日記の点数（なければ null）。**日記の本文は送らない**
- プロンプト②を書き直した：今日の入力がなければ、最近の流れと同じ曜日の傾向から今日の調子を見積もる／はかどった日に多い時間帯・場所・曜日を根拠にする／項目名を英語のまま書かない
- 返事は zod で確かめる（% は 0〜100、天気は % から決め直す、時間帯の形、場所は 2 つまで、根拠は 3 つまで）
- 保存先：`users/{uid}/forecasts/{今日の日付}`。どの日記から作ったか（`basedOnDiaryId`、日記なしは `none`）を残し、新しい日記を書いたら作り直す。作り直しに失敗したら前の予報を出す
- ホームの予報カード（手帳・クリア・ビジネスの 3 系統）：はかどり度・天気・おすすめ時間（理由）・おすすめ場所・ラッキーアイテム（理由）・向いている勉強のしかた・休み方・ハカドリのひとこと・予報の根拠・注意書き
- ハカドリの話しかけに予報（はかどり度と天気）を渡す。予報が決まるまで話しかけを待ち、1 回だけ作る

### 気分のグラフ
- 「はかどった」と答えた日に、色の帯と ★ を重ねる。触るとその日の答えも出る

### デモ用のデータ
- 「デモの日記を入れる」で、「はかどった？」の答えも入れる（はかどった日は朝の図書館・カフェ、はかどらなかった日は夜の家、という傾向つき）。昨日の分は答えずに残す（デモで答える場面を撮るため）

### 分析中のアニメーション
- `public/animations/`：`hakadori.svg`（ver1）、`moonwalk.svg`（ver2。コインの「MJ」は「♪」に変えた）、`battle.html`（ver3）
- `src/components/ui/WaitAnimation.tsx`：設定（`settings.waitAnimation`）に合わせて出す。「視差効果を減らす」設定の人には、3D の代わりに動かないハカドリ
- 設定画面に「分析中のアニメーション」を追加。段階7 の `WalkingMascot` とその CSS は消した

### PLAN.md

## 変わったこと
- 日記をつけていれば、今日何も入力しなくても、毎朝「今日のはかどり予報」が出るようになった
- 「はかどった？」の答えがたまるほど、時間帯・場所・曜日の根拠つきの予報になる

## 残った課題・引き継ぎ
- 段階9：おすすめ場所（図書館・カフェ・公園）を Places API で近くの実際の場所にする
- `gemini-3.8-flash` が混み合うと、切り替えまで最大 1 分ほど「予報中…」が出る
- ムーンウォーク（ver2）は実在の人物に似せた絵なので、応募作品・デモ動画では使わない
- メガシティ・バトル（ver3）は Three.js を CDN から読み込むため、通信量が多く、スマホでは重いことがある
