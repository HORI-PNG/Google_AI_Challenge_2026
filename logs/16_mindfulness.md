# 段階16：1分間のマインドフルネス

## 実装したこと
- `/mindfulness` に1分間の瞑想画面を追加。
- 帽子なし、黒と金の軍服風の舞台衣装、サングラス、白い前腕カバー、脚を開いて両腕を下ろすイラストを新規作成。
- 床下に全身が隠れた位置から上昇し、頂点を通って落下、着地の沈み込みから立ち直り、完全静止する1回のジャンプを実装。
- ステージの床で登場前の体を隠し、短い煙は登場時だけ表示する。
- Web Animations APIの `finished` で着地完了を受け取ってから60秒を計測する。登場の1.2秒を瞑想時間に含めない。
- 中止・画面移動でアニメーションを取り消し、キャンセルを完了扱いにしない。
- 動きを減らす設定では登場を省略して60秒を開始する。
- 途中終了・再挑戦、素材の読み込み待ち・エラー表示に対応。
- タイマーは終了時刻との差分で計算。タブ復帰時にも残り時間を再計算する。
- 手帳・ビジネスのホーム入口、およびクリアのナビゲーションに「瞑想」を追加。
- 日記の待機アニメーションは変更しない。API呼び出し・データ保存は追加しない。
