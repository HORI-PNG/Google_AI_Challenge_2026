# 段階16：1分間のマインドフルネス

## 実装したこと
- `/mindfulness` に瞑想画面を追加。各テーマのホームに「瞑想」の入口を用意した。
- 黒と金の舞台衣装・サングラスのキャラクターが、床下から跳び上がり、落下・着地して仁王立ちで静止する。
- Web Animations APIの `finished` を受け取ってから60秒を計測する。登場の1.2秒は瞑想時間に含めない。
- 残り時間は表示しない。60秒後にマイクを持ち上げ、口を開閉し、頭を動かす無音の歌唱アニメーションへ切り替える。
- 静止用と歌唱用のSVGを分け、瞑想中のキャラクターは動かさない。歌唱用SVGは `node scripts/create-mindfulness-singing.mjs` で再生成できる。
- 途中終了・再挑戦、素材の読み込み待ち・エラー表示に対応。中止・画面移動では登場アニメーションとタイマーを破棄する。
- 動きを減らす設定では登場や歌唱の動きを省略し、ポーズの切り替えだけで終了を示す。
- 画面の説明は「マイケルを1分間見つめよう」。追加のAPI・データ保存・環境変数は不要。

- スピン＋キックは正面・背面・正面と回転し、膝をたたんでから脚を伸ばす4.4秒のループ。

## 承認済み3Dキャラクターの統合

- 黒金の衣装・サングラス・肩の下までの後ろ髪を持つ、ユーザー確認済みのモデルへ表示を変更。
- 登場と60秒の静止には同じモデルの元の姿勢を使い、終了後だけ骨格アニメーションを再生する。
- 歌唱・スピン＋キック・ロボットダンス・ムーンウォークの4クリップを1つのGLBへ収録。歌唱時だけ右手のマイクを表示する。
- 服・金具・髪・靴を共通の骨格へ結び付け、足の接地とループの先頭/末尾を調整した。
- Three.jsと同梱のMeshoptDecoderで表示。GLBを約1.4MBへ圧縮し、外部CDNや新しいAPIキーは使わない。
- 画面サイズの変更、タブ非表示、動きを減らす設定、描画リソースの破棄に対応。WebGL不可時は同じモデルの透過PNGで瞑想を続けられる。
- `scripts/mindfulness-3d/` に再生成コード・CC0の元データ・出所とライセンスを保存。アプリ起動時にBlenderは不要。
- 確認用ページの4種類の見本も新しい3D表示へ変更した。
