# 段階16：1分間のマインドフルネス

## 実装したこと
- `/mindfulness` に瞑想画面を追加。各テーマのホームに「瞑想」の入口を用意した。
- 黒と金の舞台衣装・サングラスのキャラクターが、床下から跳び上がり、落下・着地して仁王立ちで静止する。
- Web Animations APIの `finished` を受け取ってから60秒を計測する。登場の1.2秒は瞑想時間に含めない。
- 残り時間は表示しない。60秒後にマイクを持ち上げ、口を開閉し、頭を動かす無音の歌唱アニメーションへ切り替える。
- 静止用と歌唱用のSVGを分け、瞑想中のキャラクターは動かさない。歌唱用SVGは `node scripts/create-mindfulness-singing.mjs` で再生成できる。
- 途中終了・再挑戦、素材の読み込み待ち・エラー表示に対応。中止・画面移動では登場アニメーションとタイマーを破棄する。
- 動きを減らす設定では登場や歌唱の動きを省略し、ポーズの切り替えだけで終了を示す。
- 画面の説明は「マイケルを1分間見つめよう」。追加のAPI・データ保存・環境変数は不要。

## 動作確認
- `npm run lint`：成功。
- `npx next typegen` 後の `npx tsc --noEmit`：成功。
- `node --test tests/unit/*.test.mjs`：既存123件成功。
- Chromium / PlaywrightでNext.jsの瞑想画面を検証。実時間で着地から60,009ms後に歌唱素材へ切り替わること、直前まで静止すること、口の開閉、タイマー非表示、再挑戦、登場中の中止、動きを減らす設定、320px・375px・736pxでの横はみ出しなしを確認。
- ブラウザ検証はwebpack開発サーバーを使用。本環境のGoogle Fonts取得問題を避けるため、検証時だけフォント応答をローカル代替フォントに置換し、既存設定と同じTailwind v4で生成したCSSを注入した。検証用の置換・スクリプトはコミットに含めない。
- webpackでの本番用ビルドも成功（検証時だけGoogle Fontsをローカルフォントに置換）。通常のフォント取得を含むTurbopackビルドは別環境での確認が必要。
- `npm test` のディレクトリ指定はこの環境のNode 24で失敗するため、単体テストは上記のファイル指定で実行した。
