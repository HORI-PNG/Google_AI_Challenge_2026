# 段階14：はかどり場所マップ（記録）

## 決めたこと（ユーザーに確認済み）
- 補助機能の ④ を、デモ動画の準備より先に作る
- 地図は OpenStreetMap ＋ Leaflet（無料・キー不要）。Google Maps JavaScript API は請求先の登録が要るので使わない

## 実装したこと
### 場所の記録（任意・初期はオフ）
- 設定画面に「日記に場所を記録する」（`settings.locationEnabled`。段階9 で隠していた設定を、この用途で出し直した）。オンにしたときにブラウザの位置情報の許可を聞く
- オンのときだけ、日記を保存したあとに場所を読み、約 100m に丸めて `diaries/{id}.location{lat, lng}` に保存（`saveDiaryLocation`）。分析は待たせない。場所が読めなくても日記は保存される。位置はログに出さない
- 日記の画面に、記録すること（オフなら設定への案内）を出す

### はかどり場所マップ `/map`
- `src/components/LeafletMap.tsx`：OpenStreetMap のタイルと色つきの丸。出典（© OpenStreetMap contributors）を出す。ブラウザでしか動かないので `next/dynamic`（ssr: false）で読み込む
- `src/components/MapScreen.tsx`：最近 60 日の、場所のある日記を読み、約 100m ごとにまとめる。色＝はかどり度（「はかどった？」の答えの平均、なければ集中の点数）、大きさ＝日記の数。丸を押すと記録、地図の下に場所ごとの一覧と色の意味
- `src/lib/placeMap.ts`：丸め、まとめ方、はかどり度、色、丸の大きさ、表示範囲
- ホームの 3 系統に入り口
- 依存：`leaflet`、`@types/leaflet`

### デモ用のデータ
- 「はかどった？」の答えの場所（図書館・カフェ・家・学校・公園）に合わせて、東京駅の近くの架空の点を日記に入れる

### PLAN.md
- 地図の技術、`location{lat, lng}` の説明

## 変わったこと
- どこで書いた日がはかどったかを、地図の色で見られるようになった（予報の「おすすめ場所」の根拠を自分で確かめられる）
