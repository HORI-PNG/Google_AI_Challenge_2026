# 段階11：おすすめの時間帯をカレンダーに入れる（記録）

## 決めたこと（ユーザーに確認済み）
- 補助機能は ③ カレンダー → ② 自分専用 AI への質問 → ① 忘却曲線 → ④ マップ の順に進める
- ② は WebLLM ではなく Gemini のまま（応募条件「Google AI を主要な手段に」と、スマホでの重さ・日本語の質のため）。Flash-Lite と質問の上限で回数を節約する
- カレンダーは Calendar API ではなく、Google カレンダーの「予定を追加」画面を開くリンクにする（無料、権限・審査が要らない）
- ④ マップは、Google マップだと請求先の登録が要るので、そのときに OpenStreetMap（Leaflet）の案で考える

## 実装したこと
- `src/lib/calendar.ts`：おすすめ時間（"10:00〜12:00"）を読み、`calendar.google.com/calendar/render?action=TEMPLATE…` の URL を作る（日本時間、24:00 は翌日の 0:00、読めない時間帯は null）
- `src/components/home/CalendarButton.tsx`：「📅 おすすめ時間（…）をカレンダーに入れる」。時間がもう過ぎていたら注意を出す
- 予定の中身：題名「勉強（はかどり予報 〇〇%）」、今日のおすすめ時間、場所（おすすめ場所）、説明（理由・向いていること・ラッキーアイテム・注意書き）
- ホームの 3 系統（手帳・クリア・ビジネス）の予報に入れた
- テスト：`tests/unit/calendar.test.mjs`（7 件）
- PLAN.md：カレンダーの作り方と使用プロダクトを直した

## 変わったこと
- 予報を見たら、そのままおすすめ時間を Google カレンダーの予定にできるようになった（予報 → 行動）

## 動作確認
- `npm test`（97 件）、`npm run test:rules`（7 件）、`npm run lint`、`npx tsc --noEmit`：成功
- ユーザーがローカルで確認：ボタンからカレンダーの画面が開き、予定が入った

## 残った課題・引き継ぎ
- 復習の予定（① 忘却曲線）もカレンダーに入れられるよう、`calendarUrl` を使い回せる
