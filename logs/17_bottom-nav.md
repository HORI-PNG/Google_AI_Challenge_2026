# 段階17：下のメニューを全テーマ共通にする（記録）

## 決めたこと（ユーザーの希望）
- クリアにだけあった「すべらせて選ぶ下のメニュー」を、7 つのテーマすべてで使う

## 実装したこと
- `src/components/GlassNav.tsx` を `src/components/BottomNav.tsx` に名前を変え、テーマの条件を外した。ログイン後のどの画面にも出す（最初の登録 `/welcome` は除く）
- `globals.css`：`.bottom-nav`（面＝カードの色＋ぼかし）、`.bottom-nav-lens`（真ん中の丸＝`--soft-accent`）をテーマのトークンで描く。クリアは今までのすりガラスの見た目を `[data-theme="clear"]` で保つ。よぞらは丸の上の光を弱めた
- 手帳・ビジネスのホームからも、ヘッダーの「日記を書く」・ユーザーのボタンと、入り口の列（`EntryRow`）を外した（メニューと役目がかぶるため。クリアに合わせた）。使わなくなった `AccountMenu`・`EntryRow` と、クリア用のボタンの CSS を消した
- README：「瞑想機能だけを確認する」の節を、Fork を clone する手順から、`npm run dev` で `/mindfulness` を開く短い説明に直した（段階16 の merge 後の内容に合わせた）

## 変わったこと
- どのテーマでも、下のメニューから グラフ・聞く・日記を書く・復習・場所・瞑想・ユーザー（とテーマ）を開ける
- ホームの上は日付だけになり、すっきりした
