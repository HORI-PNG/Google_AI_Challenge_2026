# Re:Note — Figma Make 用デザイン指示書

このファイルの内容を、そのまま Figma Make に貼り付けて使う。
（Figma Make で作ったデザインは、あとで Next.js（App Router）のアプリに移植する。Figma Make では React で作ってよいが、移植しやすいように「技術の約束」を必ず守ること）

---

## 1. アプリの概要

**Re:Note（リノート）** は、気持ちを書くと「今日のはかどり」が分かる、学生向けの日記アプリ。

- その日の気持ちを「書く・話す・選ぶ」のどれかで日記にすると、AI（Gemini）が感情を **0〜100 点**（気分・元気・集中しやすさ・ストレス）にする
- 小さな鳥のキャラクター **「ハカドリ」** が、気分に合わせてひとこと返してくれる
- 日記がたまると、**「今日のはかどり予報」**（天気予報のような表示）と、おすすめの時間帯・場所・ラッキーアイテムが出る
- キャッチコピー：「気持ちを書くと、今日の『はかどり』が分かる。」「日記が、明日の自分の天気予報になる。」

**使う人**：中学生〜大学院生。毎日開きたくなる、やさしくて少し楽しい雰囲気にする。勉強アプリのような堅さや、医療アプリのような冷たさは避ける。

**大事にしたいこと**
- 気持ちを書く場所なので、**安心できる・責められない** 雰囲気（赤い警告色や「もっと頑張れ」のような強い表現は使わない）
- **UI テーマの切り替え** と **キャラクター** は、続けてもらうための中心の機能。テーマごとに雰囲気がはっきり変わるようにする
- スマホで片手で使える（主な操作は画面の下半分に置く）

## 2. 技術の約束（移植のため、必ず守る）

- **React + TypeScript + Tailwind CSS** で作る
- 移植先のアプリは **Next.js（App Router）+ TypeScript + Tailwind CSS**。Next.js に移しやすいように、次を守る
  - Vite に固有の書き方を使わない（`import.meta.env`、画像を `import` で読み込む書き方など）。画像は `public/` に置き、`/images/xxx.svg` のようなパスで参照する
  - `react-router` などのルーターを使わない
  - `window` や `localStorage` は、イベントの中か `useEffect` の中だけで使う（サーバーで描画されても壊れないように）
  - 見た目だけの部品と、状態（`useState` など）を持つ部品をなるべく分ける
- **スマホ幅 375px** を基準にする。画面の最大幅は 448px で中央寄せ（PC で開いても崩れない）
- 画面ごとにコンポーネントを分ける（`HomeScreen`、`DiaryScreen` など）。1つのファイルに全部を書かない
- 画面の切り替えは、ルーターを使わず `useState` で十分（移植先は Next.js のページになる）
- データはすべて **ダミー（架空）** をコンポーネントの外に定数で置く。実在の人の名前や日記は使わない。バックエンドやログインの処理は作らない（見た目だけでよい）
- **色・フォント・角丸は、すべて CSS 変数** で指定する。Tailwind の色クラスに直接 `bg-orange-400` のように書かない。テーマは `<html data-theme="テーマID">` で切り替える
- 使ってよい変数名（この名前のまま使う。足りなければ追加してよい）

| 変数 | 役割 |
|---|---|
| `--background` | 画面の背景 |
| `--foreground` | 本文の文字 |
| `--muted` | 補足の文字（日付、説明など） |
| `--card` | カードの背景 |
| `--accent` | 主ボタン、選択中のタブ、強調 |
| `--accent-foreground` | `--accent` の上の文字 |
| `--border` | 線、入力欄の枠 |
| `--series-mood` / `--series-energy` / `--series-focus` / `--series-stress` | グラフの4本の線の色 |
| `--chart-grid` / `--chart-axis` | グラフの目盛り線・軸 |
| `--font-body` / `--font-heading` | 本文・見出しのフォント |
| `--font-number` | 点数やパーセントなど数字のフォント（テーマによって変えてよい） |
| `--radius` | カードやボタンの角丸 |
| `--shadow` | カードの影 |
| `--card-blur` | カードの背景のぼかし（すりガラス。不要なテーマは `0px`） |
| `--surface-gradient` | 背景やカードのグラデーション（不要なテーマは `none`） |

- **テーマによって画面の構成（並べ方）が大きく変わってよい**。そのために、次の作り方にする
  - 各テーマは、色などの変数に加えて **レイアウトの系統（`layout`）** を1つ持つ：`notebook`（手帳）／`glass`（クリア）／`office`（ビジネス）
  - 画面ごとに、データと状態を持つ部品（例：`HomeScreen`）と、見た目の部品（例：`HomeNotebook`、`HomeGlass`、`HomeMetal`、`HomeOffice`）に分ける。**見た目の部品は、どの系統でも同じ props（同じデータ）を受け取る**
  - 系統が同じテーマどうしは、同じ見た目の部品を使い、CSS 変数だけで違いを出す
  - テーマの定義は1か所にまとめる（例：`themes.ts` に `{ id, name, layout, description }` の配列）

- アイコンは `lucide-react` を使ってよい。絵文字も使ってよい
- フォントは Google Fonts の日本語フォントから選ぶ（例：Zen Maru Gothic、M PLUS Rounded 1c、Noto Sans JP、Klee One、Noto Serif JP）
- 文字の大きさは本文 16px 以上。補足の文字も 12px 未満にしない。文字と背景のコントラストは十分にとる
- ボタンなど押せるものは、高さ 44px 以上

## 3. 作ってほしい画面

すべて日本語で、ダミーのデータを入れる。

### ① ログイン（初めて開いたとき）
- アプリ名「Re:Note」、キャッチコピー、ハカドリの絵
- 「Google でログイン」ボタン
- 「日記はあなただけが読めるように保存されます」という一文

### ② はじめまして（初回の基本情報の登録）
- 「はじめまして！ 日記を書く前に、あなたのことを少しだけ教えてください」
- 入力：名前、ニックネーム（「ハカドリがこの名前で呼びます」）、学年（中学1年〜大学院（博士）、その他 から選ぶ）
- 「名前とニックネームは Gemini には送りません」という一文
- 「はじめる」ボタン

### ③ ホーム
上から順に：
1. 日付（例：11月14日（土））と、テーマ・設定へのボタン
2. **ハカドリの話しかけ**：「ほり さん、今日はどんな一日だった？」（吹き出し）
3. **今日のはかどり予報カード**（一番目立たせる）
   - はかどり度 **78%** と天気（晴れ ☀️／くもり ☁️／雨 ☔ の3種類。今回は晴れ）
   - おすすめの時間帯「10:00〜12:00」
   - おすすめの場所「静かなカフェ」「図書館」
   - ラッキーアイテム「あたたかい飲み物」と理由「ストレスが高めの日に、落ち着けた日が多かったため」
   - 今日向いていること「暗記より問題演習」
   - ひとこと「今日は集中しやすい日。午前中に一番大事なことをやろう」
4. **昨日の日記のふりかえり**：ハカドリのひとことと、4つの点数の小さな表示
5. **「昨日の勉強ははかどった？」** の3択（😣 いまいち／🙂 まあまあ／😆 はかどった）
6. 「気分のグラフ」へのカード
7. 画面の下に固定した大きな「日記を書く」ボタン

### ④ 日記を書く
- 上に「✏️ 書く／🎙️ 話す／☑️ 選ぶ」のタブ
- **書く**：大きな入力欄（プレースホルダー「うれしかったこと、疲れたこと、分かったこと…思ったままに書いてね」）、文字数（0 / 4000）、「保存して分析する」
- **話す**：次の4つの状態をそれぞれ見せる
  1. 待機：「今日あったことや気持ちを、そのまま話してね（2分まで）」「長く話すと、全部は文字にできないことがあるよ」と「🎙️ 話しはじめる」
  2. 録音中：赤すぎない点滅の印、「聞いているよ」、経過時間「0:42 / 2:00」、「話し終わった」
  3. 文章にしている途中：「Gemini が声を文章にしています…」
  4. 確認：文章になったものを直せる入力欄、「保存して分析する」「録り直す」
- **選ぶ**：チップ（押すと色が変わる丸いボタン）で選ぶ
  - 気分（1つ）：😄 とても良い／🙂 良い／😐 ふつう／😞 いまいち／😢 つらい
  - 体調（1つ）：💪 元気／🙂 ふつう／😪 眠い／🥱 疲れた／🤒 体調が悪い
  - 今日あったこと（いくつでも）：授業、テスト勉強、宿題・課題、塾、部活、研究、バイト、友だちと過ごした、家族と過ごした、家でのんびり、その他
  - ひとこと（任意、100文字まで）
  - 気分と体調を選ぶまでボタンは「気分と体調を選んでね」で押せない

### ⑤ 分析中
- 「日記を保存しました。ハカドリが日記を読んでいます…」「混み合っているときは、少し時間がかかります」
- ハカドリが考えているような、やさしい待ちの演出

### ⑥ 分析の結果
- **ハカドリのひとこと**（吹き出し）：「疲れてるのに頑張ったね！明日は朝のうちに少しだけ復習しよう」
- **今日の気持ち**：気分 72点、元気 55点、集中しやすさ 80点、ストレス 30点（ストレスには「低いほど良い」と添える）。バーやメーターなど、ひと目で分かる形で
- 感情のラベル：「やる気」「少し疲れ」
- 理由：「部活で疲れているが、テストが近くてやる気は高い」
- **今日学んだこと**：「二次関数：平方完成で頂点が分かる」
- 「ホームへ」ボタン
- 次の2つの別パターンも作る
  - **分析に失敗したとき**：「日記は保存しました。Gemini が混み合っていて、分析できませんでした。少し時間をおいて、もう一度分析できます」と「もう一度分析する」「あとで分析する」
  - **つらい気持ちが書かれていたとき**：点数は出さない。「書いてくれてありがとう。今の気持ちを、信頼できる人や相談窓口に話してみてほしいな」と、相談窓口のカード3つ（24時間子供SOSダイヤル 0120-0-78310、よりそいホットライン 0120-279-338、まもろうよ こころ（厚生労働省））。落ち着いた、やさしい見た目にする（警告のような赤は使わない）

### ⑦ 気分のグラフ
- 期間の切り替え「1週間／1か月」
- 凡例（押すと線の表示・非表示）：気分・元気・集中・ストレス（低いほど良い）
- 4本の折れ線グラフ（0〜100点）。日記のない日は線が途切れる。グラフに触れるとその日の点数が出る
- 期間の平均点のカード 4つ（例：気分の平均 62点）
- 「表で見る」（開くと日付ごとの点数の表）
- グラフの線は 2px、点は直径 8px に背景色の縁取り、目盛り線は細く目立たない色

### ⑧ テーマを選ぶ（設定）
- 7つのテーマを、色と雰囲気が分かる小さな見本カードで並べる（「やさしい」「スタイリッシュ」の2つのまとまり）。選ぶとすぐに画面全体が変わる。構成が変わるテーマは、見本カードでも構成の違いが分かるようにする
- 上に **「今日の気分には、このテーマはどう？」** というおすすめ（例：ストレスが高い日は落ち着いたテーマ）。切り替えるかは本人が決める
- そのほか：基本情報の変更、ログアウト

### ⑨ ハカドリ（キャラクター）
- 小さな鳥。丸くて、やさしく、少しとぼけた感じ。口ぐせは「ピッ」、一人称は「ボク」
- 表情を5種類：にっこり（気分が高い）／ふつう／心配（気分が低い）／ねむい（元気が低い）／おうえん（やる気）
- この段階では仮の絵でよい（シンプルな図形や SVG で）。テーマに合わせて色が変わるとうれしい

## 4. テーマ（7種類）

テーマごとに **色・フォント・背景の雰囲気** をはっきり変える。下は案なので、より良い組み合わせがあれば変えてよい。
⑧のテーマを選ぶ画面では、7つを「やさしい（手帳）」と「スタイリッシュ（クリア・ビジネス）」の2つのまとまりに分けて並べる。

### 4-1. 手帳の系統（`layout: notebook`）— 5種類
同じ画面の構成で、色・フォント・背景だけを変える。丸みがあって、カードを縦に並べる、やさしい手帳のような構成。

| ID | 名前 | 雰囲気 | 色の案 | フォントの案 |
|---|---|---|---|---|
| `kotori` | ことり（標準） | やさしい手帳。生成りの紙 | 生成り、コーラル、こげ茶 | Zen Maru Gothic |
| `yozora` | よぞら | 夜に静かに書く。ダークモード | 紺、月の黄色、薄い灰色の文字 | Zen Maru Gothic |
| `mori` | もりのとしょかん | 落ち着いて集中できる | 生成り、深い緑、木の茶色 | Klee One または Noto Serif JP |
| `soda` | ソーダ | 元気でポップ | 白、水色、レモン | M PLUS Rounded 1c |
| `sakura` | さくらもち | ふんわりかわいい | 桜色、抹茶色 | Zen Maru Gothic |

### 4-2. クリア（`layout: glass`、ID：`clear`）
- **最近のスマホアプリのような、モダンで透明感のある** テーマ
- 明るい背景に、やわらかい色のぼかし（グラデーションの光）を敷き、カードは **すりガラス**（半透明＋背景のぼかし）
- 大きめの角丸、余白を広く、影はごく薄く。色は淡いトーンの中に、1色だけはっきりした差し色
- 構成の例：はかどり予報を画面の上半分いっぱいの大きなカードにし、その下に小さなカードを2列のタイルで並べる。下に、丸いボタンの並んだ固定のナビゲーション
- フォント：Noto Sans JP または M PLUS 1p（すっきりしたゴシック）
- 実在の会社のロゴや、特定の会社を思わせる配色（決まった4色の組み合わせなど）は使わない

### 4-3. ビジネス（`layout: office`、ID：`office`）
- **会社の人が使う業務アプリのような**、情報が整理されて、密度の高いテーマ
- 白と薄い灰色の背景、紺の差し色。角丸は小さく（4px 程度）、影はほぼなし、細い線で区切る
- 絵文字や飾りは控えめにし、アイコン（lucide-react）を使う。ハカドリは小さく、右上や見出しの横に控えめに置く
- 構成の例：上に見出しのバー（日付・アプリ名・メニュー）、その下に「今日のはかどり予報」を表の形（項目名｜内容）で、点数は小さな数値のタイル4つを横に並べる。日記の一覧は表のように1行ずつ
- 言葉づかいは、ラベルや見出しを少し事務的にしてよい（例：「今日のはかどり予報」→「本日のコンディション予測」）。ただし、ハカドリの返事の文は変えない
- フォント：BIZ UDPGothic（読みやすい業務向けのゴシック）
- 大学生・大学院生や社会人に向けて「仕事の調子の管理にも使える」ことを見せるテーマ

### 気分でのおすすめ
- 目安：気分が高い日 → ソーダ／ストレスが高い日 → もりのとしょかん／夜遅い時間 → よぞら／ふつう → ことり
- クリア・ビジネスは、好みで選ぶテーマなので、おすすめには出さない
- グラフの4本の線の色（`--series-*`）は、色覚の多様性に配慮して選んだ次の4色を基本にする。テーマに合わせて変えるときも、**4色が互いに見分けやすいこと** を守る
  - 明るい背景：気分 `#2a78d6`（青）、元気 `#eb6834`（橙）、集中 `#1baf7a`（水色）、ストレス `#eda100`（黄）
  - 暗い背景（よぞら）：気分 `#3987e5`、元気 `#d95926`、集中 `#199e70`、ストレス `#c98500`
  - すりガラス（クリア）の上でも線が見えるように、グラフのカードは不透明度を上げるか、白に近い面を敷く
- グラフの文字は線の色を使わず、文字の色（`--foreground` / `--muted`）で書く
- どのテーマでも、文字と背景のコントラストを十分にとる

## 5. 避けること

- 実在の人の名前・写真・日記を使う
- 赤い警告色で気持ちを責めるような表現、点数で優劣をつける表現（「悪い日」など）
- 1 つのファイルにすべての画面を書く、色をコードに直接書く
- 系統ごとに、受け取るデータ（props）の形を変える（構成は変えてよいが、データの形は同じにする）
- 実在の会社のロゴやブランドをまねる
- PC 向けの横長のレイアウト（スマホが基準）
